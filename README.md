***專案簡介***  
   我做了一個繁體中文的資料結構複習網站，內容包含堆疊、佇列和中序轉後序。首頁把中序轉後序拆成數個操作步驟，讓讀者看到每一步的堆疊內容和後序輸出。每個課程頁也附一道小練習。
   

**專案目的**

這是一個給初學者複習資料結構的繁體中文網站。每頁讓讀者學會一個概念、看懂一個操作範例，再試做一題。預設讀者已看過陣列和基本算式。

專案結構與命名

位置  用途
index.html  首頁、中序轉後序示範及課程目錄
lessons/*.html  每個概念一個獨立課程頁
assets/style.css  所有頁面共用的版面、顏色與手機排版
assets/demo.js  首頁固定算式的逐步操作
README.md  操作、發布及繳交說明
