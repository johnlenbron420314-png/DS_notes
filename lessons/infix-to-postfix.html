中序轉後序

中序把運算子放在兩個運算元中間，例如 A + B。後序把運算子放在兩個運算元後面，例如 A B +。

操作規則

  1. 從左到右讀取算式。遇到運算元就直接輸出。
  2. 遇到左括號就放入堆疊。遇到右括號時，依序取出並輸出運算子直到左括號，再移除左括號。
  3. 這裡只處理左結合的 +、-、*、/。讀到運算子時，先依序取出並輸出堆疊頂端優先順序較高或相同的運算子。讀到左括號或堆疊已空時，停止取出，再放入目前的運算子。乘除優先於加減。
  4. 讀完整個合法算式後，從頂端依序輸出剩下的運算子。

範例

以 A + B * C 為例。乘法優先於加法，所以讀到 * 時，+ 留在堆疊裡。

讀取      堆疊（底到頂）  後序輸出
A         空              A
+         +               A
B         +               A B
*         + *             A B
C         + *             A B C
掃描結束  空              A B C * +

小練習

試把 (A + B) * C 轉成後序。

查看解答

A B + C *。讀到右括號時先輸出 +，乘法運算子最後輸出。
